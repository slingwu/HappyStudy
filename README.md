# 周周的学习乐园 🌈

> 为学龄前宝宝打造的离线早教网页：识字、英语、绘本、古诗、动画、数学，点一点听一听，单个 HTML 文件离线就能用。

## 项目简介

**周周的学习乐园** 是一款为学龄前小朋友打造的离线早教小网站，一个网页文件就能跑——不依赖网络、不用装 App，点一点、听一听，陪周周在玩中认识世界。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 🔤 **识字** | 100 个常用汉字，配拼音、组词、真实照片和卡通大字卡，点字即听真人发音 |
| 🔤 **英语** | 常用单词配图 + 预生成的真人发音音频，手机和电脑都能稳定出声 |
| 📖 **绘本** | 精选分级读物，点开就能听朗读、逐句高亮，陪孩子一起读 |
| 📜 **古诗** | 经典儿歌与古诗，点开听朗读 |
| 🎬 **动画** | 超级飞侠、百变校巴等适龄动画，快乐启蒙 |
| 🔢 **数学** | 趣味算术，边玩边练 |

## 贴心细节

- **朗读随时可停**：绘本和古诗朗读时，点右上角关闭、点页面别处、或切换到其他模块，都会自动停下，不吵不卡。
- **真正离线可用**：所有发音和图片都内嵌在单个 `index.html` 文件里，下载到本地双击就能用，断网也照常学习。
